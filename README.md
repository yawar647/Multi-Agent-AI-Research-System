# Multi-Agent Research Assistant

## Project Overview

The **Multi-Agent Research Assistant** is an AI-powered application designed to automate web-based research and report generation using multiple specialized AI agents.

Instead of relying on a single language model to answer questions from its existing knowledge, the system coordinates a team of agents that search the web, extract relevant information, generate structured research reports, and evaluate the final output.

Given a research topic, the application follows a collaborative workflow in which each agent performs a specific task. The goal is to produce a detailed, well-organized report based on information gathered from external sources.

The project explores the use of Large Language Models (LLMs), LangChain Expression Language (LCEL), web research tools, and multi-agent workflows to automate complex research tasks.

## Project Objectives

- Automate web-based research on user-provided topics.
- Retrieve relevant information from online sources.
- Extract and organize useful research content.
- Generate structured and detailed research reports.
- Evaluate report quality through a dedicated review agent.
- Demonstrate collaboration between specialized AI agents.
- Explore agentic AI architectures using Python and LangChain.

## Key Features

### 1. Search Agent

The Search Agent discovers relevant online sources for a given research topic.

Responsibilities:

- Search for relevant information on the web.
- Identify potentially useful sources.
- Gather information from available online resources.
- Provide research material for the next stage of the workflow.

### 2. Reader Agent

The Reader Agent processes the sources identified during the search stage.

Responsibilities:

- Extract meaningful information from web pages.
- Identify relevant facts and supporting details.
- Organize the collected content.
- Prepare research material for report generation.

### 3. Writer Agent

The Writer Agent transforms the collected research into a structured report.

Responsibilities:

- Organize findings into logical sections.
- Summarize information gathered from the sources.
- Develop clear explanations based on the available research.
- Generate a detailed and readable report.

### 4. Critic Agent

The Critic Agent reviews the report generated by the Writer Agent.

Responsibilities:

- Evaluate the report's clarity and structure.
- Assess relevance and completeness.
- Identify weaknesses and areas for improvement.
- Provide feedback and a quality score according to the configured evaluation criteria.

The Critic Agent adds a review stage to the research workflow. Its evaluation does not guarantee that every statement in the report is factually correct.

## System Architecture

The application follows a multi-agent research workflow.

**Research pipeline:**

1. **User Input:** The user submits a research topic.
2. **Web Search:** The Search Agent identifies relevant online sources.
3. **Content Extraction:** The Reader Agent extracts useful information from the selected sources.
4. **Report Generation:** The Writer Agent organizes the findings into a structured report.
5. **Quality Evaluation:** The Critic Agent reviews the generated report and provides feedback.
6. **Final Output:** The application presents the research results to the user.

The system uses specialized agents to divide the research process into manageable tasks. LangChain and LCEL support the composition and execution of the workflow, depending on the implementation.

Before running the project, ensure that you have:

- Python installed on your system.
- Git installed to clone the repository.


Install the required Python packages:

```bash
pip install -r requirements.txt
```

If the application requires API keys, configure them using the environment variable names expected by your code.

### 5. Run the Application

If `app.py` is the application entry point, launch the project with:

```bash
python app.py
```

Follow the application's interface or prompts to enter a research topic and generate a report.

The exact configuration and launch requirements depend on the implementation.

## Limitations and Considerations

- Research quality depends on the availability, relevance, and reliability of online sources.
- Language models may generate inaccurate or unsupported information.
- Automated web access may be limited by website restrictions or changes in page structure.
- A quality score from the Critic Agent does not guarantee factual accuracy.
- Important findings and references should be verified before academic or professional use.
- Actual autonomy, memory management, iterative refinement, and error handling depend on the implementation.
